# SKIN1004 E-Commerce Website

A responsive skincare e-commerce website built with React, Vite, Firebase Authentication, and Firestore.  
The project provides users with product browsing, authentication, shopping cart functionality, and an admin dashboard for managing products.

## 🚀 Features

### User Features
- Browse skincare products
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- User registration
- User login/logout
- Forgot password functionality
- Responsive design for mobile and desktop

### Admin Features
- Admin dashboard
- Add new products
- Update product information
- Delete products
- Manage product data stored in Firestore

## 🛠️ Technologies Used

### Frontend
- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Bootstrap 5

### Backend / Database
- Firebase Authentication
- Firebase Firestore Database

### Tools
- VS Code
- Git & GitHub
- npm
